## 分支结构

```
master — 唯一分支，所有开发直接提交到此
```

## 提交规范

格式: `<类型> <模块> — <说明>`

```
fix   battle — 修复目标选择高亮位置错误
feat  core   — 实现三层属性结构
refac skill  — 迁移所有技能到命令队列
```

## 关键规则

1. 每次提交前确认编译通过
2. 提交前跑通一次完整战斗循环
3. 提交消息遵循 `<类型> <模块> — <说明>` 格式
