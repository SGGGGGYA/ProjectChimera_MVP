## 核心架构

暗黑地牢的角色系统是 **数据驱动 + 组件化** 设计。角色是装载了大量配置数据的容器，通过配置文件描述，而非硬编码。

### HeroClass — 职业模板

```csharp
class HeroClass {
    string id;            // "crusader", "plague_doctor"
    float[] hpPerLevel;   // 每级 HP
    float speed, accuracy, critChance, dodge, protection;
    ResistanceProfile resistances;
    List<CombatSkill> skills;
    List<CampingSkill> campingSkills;
    List<AfflictionEntry> afflictions;
    List<VirtueEntry> virtues;
}
```
