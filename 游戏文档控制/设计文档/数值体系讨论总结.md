## 核心数值设计

| 讨论模块 | 达成方案 |
|:---|:---|
| 基础伤害公式 | 减法公式：`(技能基础×力系 + 武器) × 修正 - 防御` |
| 属性面板 | HP/VIT/STR/AGI/INT/SPD/DEF/ACC/DOD/压力抗性 |
| 叠加契约 | "源-类型"双维乘法模型 |
| 成长曲线 | 指数经验曲线；命名时刻 5% 全属性跃升 |
| 压力系统 | 战斗中产生，首都休整/die 酒馆缓解，满值美德/折磨 |
| 战斗时间消耗 | `0.2 + (敌方总等级/100)` 天 |
| 绝境意志 | 战力比 < 1:1.5 时触发减伤+减压 |

## 数组结构审查

| 审查对象 | 诊断 | 重构方案 |
|:---|:---|:---|
| 单位属性数组 | 扁平键值对 → 数据爆炸 | **三层属性结构** ✅ 已实现 |
| 技能效果数组 | 混合效果顺序混乱 | **命令队列** ✅ 已实现 |
| 怪物掉落数组 | 固定列表无惊喜 | **标签智能掉落** ✅ 已实现 |
| 属性叠加 | 全加法膨胀 | **源-类型乘法** ✅ 已实现 |
| 美德/折磨判定 | 纯随机无叙事 | **上下文感知抽取** ✅ 已实现 |
