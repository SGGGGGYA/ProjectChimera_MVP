# 术语表

| 术语 | 定义 |
|:---|:---|
| **宏观天 (Macro Turn)** | 世界地图层面的一个回合 |
| **领袖 (Sovereign)** | 玩家在开局时选择的、永不死的主角单位 |
| **冒险者 (Adventurer)** | 可招募的"工具人"单位，遵循永久死亡规则 |
| **命名 (Anointing)** | 冒险者满足条件后，由玩家赐予称号的事件，是养成系统的核心节点 |
| **场景切换 (Scene Transition)** | 从地图到独立战斗场景的切换过程 |
| **斥候报告 (Scout Report)** | 战斗前的信息面板，是战术决策的依据 |
| **命令队列 (Command Queue)** | 技能由原子命令按顺序组成，前序完成再执行后续 |
| **三层属性** | 核心属性(Primary) → 派生属性(Derived) → 修饰属性(Modifiers) |
| **源-类型乘法模型** | 不同"源"之间乘法叠加，同源内部加法叠加 |
| **伤害浮动** | 最终伤害 × [0.85, 1.15] 均匀随机 |
