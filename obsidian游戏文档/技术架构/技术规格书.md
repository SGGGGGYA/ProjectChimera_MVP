# 技术规格书

**版本**: V2.0 · **状态**: 预生产阶段
**原始文件**: `部署文档.md`

---

> ⚠️ **勘误**：本文档中关于"Visual Scripting"的提及不准确——项目实际采用纯 C# 脚本开发。

## 技术选型（实际）

| 项目 | 实际方案 |
|:---|:---|
| 引擎 | **团结引擎 1.8.5**（Tuanjie Engine，Unity 2022.3.62t7 中国版） |
| 开发语言 | 纯 C# 脚本 |
| 架构 | 命令队列 + 事件驱动 |
| UI 框架 | Unity uGUI（代码动态生成，无场景编辑） |
| 动画 | Spine 2D 骨骼动画 |
| 数据持久化 | `JsonUtility` JSON 序列化 |
| 版本控制 | Git（单 master 分支） |

## 系统架构

```
[玩家输入]
     ↓
[GameManager — 状态机] ←→ WorldMap / Battle / Menu
     ↓
[地图模块] [经营模块] [小队模块] [战斗模块]
     ↓
[数据持久化层 (Save/Load)]
```

### 模块职责
- **GameManager**: 全局状态管理，场景切换，数据传递
- **地图模块**: 网格渲染、小队移动、事件触发
- **经营模块**: 资源产出与消耗（待完善）
- **小队模块**: 英雄数据、怪癖、装备、技能、压力
- **战斗模块**: 战场逻辑、回合制战斗、压力/崩溃判定

## 存档方案

- **策略**: 全量存档
- **方法**: 宏观天开始时，GameState 序列化为 JSON
- **注意**: 战斗中途不允许存档
