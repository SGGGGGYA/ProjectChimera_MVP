## 核心重构

### 单位属性 → 三层属性结构 ✅
```
核心属性(Primary) → 派生属性(Derived, 公式计算) → 修饰属性(Modifiers, 统一增益列表)
```

### 技能效果 → 命令队列 ✅
```
技能由原子命令(DealDamage/ApplyStatus/MoveUnit等)按顺序组成
```

### 怪物掉落 → 标签智能掉落 ✅
```
怪物定义 tag_filter + rarity_range，运行时动态抽取
```

### 属性叠加 → 源-类型乘法 ✅
```
不同"源"之间乘法叠加，同源内部加法叠加
```

### 美德/折磨 → 上下文感知抽取 ✅
```
压力事件和条目标签化，满值时优先匹配标签
```
