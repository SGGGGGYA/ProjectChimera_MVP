## 公式体系

### 伤害公式
```
最终伤害 = max(1, round((技能基础 + 武器攻击 + STR/AGI 系数) × 伤害修正 × 暴击倍率 - (DEF_Effective × 0.5)))
```
- 伤害浮动: ×[0.85, 1.15]
- 暴击: 1.5x 倍率
- 标记增伤: ×1.2（待确认）

### 命中公式
```
命中率 = Clamp(90% + (ACC - DOD) × 1%, 5%, 98%)
```

### 暴击公式
```
暴击率 = Clamp(5% + CRT × 1%, 1%, 50%)
```

### 经验曲线
```
升级所需经验 = 100 × 2^(等级 - 1)  [上限 5 级]
```

## 源-类型乘法模型

不同"源"（天赋/地形/怪癖/装备/Buff）之间乘法叠加，同源内部加法叠加。所有百分比类加成遵循边际效用递减。
